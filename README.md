## 一、项目简介

QuizLab 是一个面向课程练习场景的**题库管理后台**，包含「数据概览、题库管理、试卷管理、用户管理」四个模块，外加登录态与 404 兜底页。项目使用 **Vue 3 + Vite + Element Plus** 组合式 API 实现，采用「深色侧边导航 + 顶栏 + 内容区」的后台布局，数据通过 `localStorage` 持久化，刷新页面不会丢失。

## 二、技术栈

| 类别 | 说明 |
| ---- | ---- |
| 框架 | Vue 3.5（`<script setup>` 组合式 API） |
| UI 组件库 | Element Plus 2.9 |
| 路由 | vue-router 4（History 模式 + 全局前置守卫） |
| 构建工具 | Vite 5 |
| 状态/数据 | `reactive` 自建轻量 store + localStorage 持久化 |
| 样式 | 原生 CSS（scoped）+ CSS 变量主题 |

## 四、功能说明

### 登录 `/login`

- 演示账号 `admin` / `123456`，页面提供「填入演示账号」一键填充；
- 校验账号是否存在、密码是否正确、账号是否被停用，并分别给出提示；
- 登录成功写入本地登录态，未登录访问任意后台页面会被重定向回登录页（带 `redirect` 参数）；
- 「记住我的账号」会把账号缓存在本地，下次自动回填；
- 支持「退出登录」，退出后清理登录态。

### 数据概览 `/dashboard`

- 欢迎横幅展示发布率仪表盘（题目发布比例）；
- 四张统计卡：题目总数、试卷总数、成员数量、平均正确率（按全部答题记录加权计算）；
- 难度分布条形图、分类覆盖进度条，均由真实数据实时计算；
- 最近更新题目表、待处理事项（未发布题目 / 草稿试卷 / 停用账号 / 低正确率题目）。

### 题库管理 `/questions`

- 关键词（题干模糊匹配）+ 分类 + 难度 + 题型四维筛选，支持回车查询与一键重置；
- 表格展示题干、分类、题型、难度、答案、正确率（进度条）、发布开关；
- **新增 / 编辑**使用右侧抽屉表单：题型联动（单选 / 多选 / 判断），选项可动态增删（2~6 个），分值 1~20，支持「立即发布」；
- 表单校验：题干长度、分类必选、选项完整性、答案必选、分值范围；
- 支持**多选批量删除**，删除题目时同步清理试卷中的引用，避免出现空题目；
- 分页支持每页 5 / 8 / 10 / 20 条，删除或筛选后自动修正页码。

### 试卷管理 `/papers`

- 顶部概览：试卷总数、已发布、草稿、平均题量；
- 试卷名称模糊搜索；
- **新建 / 编辑试卷**：名称、分类、时长、状态 + `el-transfer` 穿梭框选题，实时统计题数与总分（自动累加题目分值）；
- **预览试卷**：描述列表 + 题目清单（题型、答案、难度、分值）；
- 一键发布 / 下线（二次确认）、删除（二次确认）。

### 用户管理 `/users`

- 按姓名 / 账号 / 邮箱模糊查询，支持角色、状态筛选；
- 表格展示头像、姓名、账号、角色、邮箱、手机号、加入时间、状态开关；
- **新增成员**：账号格式校验（字母开头、3~20 位）、唯一性校验、密码长度校验、邮箱格式校验、手机号格式校验；
- 编辑成员（账号不可改）、停用 / 启用账号、删除成员（演示账号 `admin` 受保护）；
- 停用账号将无法在登录页登录。

## 五、与参考示例的差异

参考示例是 Vue 2 + Element UI 的「用户管理 + 题目管理」双页后台；本项目在保持同类业务语义的前提下，做了以下重构：

| 维度 | 参考示例 | 本项目 |
| ---- | ---- | ---- |
| 框架 | Vue 2 选项式 API | Vue 3 组合式 API（`<script setup>`） |
| 构建 | Vue CLI 5（Webpack） | Vite 5 |
| 布局 | 顶部白色标题栏 + 左侧白色菜单 | 深色渐变侧边栏（可折叠）+ 顶栏面包屑 |
| 页面 | 用户管理、题目管理 | 登录、数据概览、题库、试卷、用户、404 |
| 数据 | 组件内静态数组，刷新即重置 | 独立 store + localStorage 持久化 |
| 交互 | 弹窗 + 基础分页 | 抽屉表单、批量操作、穿梭框组卷、登录守卫 |
| 题型 | 仅单选 | 单选 / 多选 / 判断，选项数可增减 |

## 六、运行与部署

```bash
npm install      # 安装依赖
npm run dev      # 本地开发，默认 http://localhost:5173
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览构建产物
```

部署说明：

- **Vercel**：导入仓库后框架预设选 Vite，构建命令 `npm run build`，输出目录 `dist`；仓库内已提供 `vercel.json`，负责 SPA 路由重写与静态资源缓存头。
- **Netlify / Cloudflare Pages**：构建命令与输出目录相同，另需把 `dist/index.html` 作为 404 回退（SPA 模式）。

## 七、说明

后端接口未接入，数据由前端预置并在浏览器 `localStorage` 中维护；顶栏「重置演示数据」按钮可随时恢复初始内容。生产环境请把 `src/store/session.js` 中的本地假 token 替换为真实后端凭证。
